# ChatBuddy – Python Chatbot

## Project Overview
ChatBuddy is a simple chatbot developed using Python in Jupyter Notebook as part of my Computer Science coursework.

The project was completed in four parts, gradually introducing different programming concepts to build a chatbot that can recognise user inputs and generate suitable responses.

## Features
- Recognises greetings such as "Hi" and "Hello".
- Responds to tea-related messages.
- Handles thank-you messages and goodbye conversations.
- Remembers the user's name and favourite colour.
- Uses regular expressions for pattern matching.
- Loads chatbot responses from a JSON file.
- Applies basic Natural Language Processing (NLP) techniques.
- Performs tokenisation, stemming, lemmatisation and synonym replacement.

## Testing
The chatbot was tested using different inputs, including:
- Greeting messages such as "Hi" and "Hello".
- Different intents such as "Thank you", "Tea", and "Goodbye".
- NLP preprocessing using the sentence "I was running and felt unhappy."

The tests demonstrated that the chatbot could recognise different inputs and apply the implemented text-processing techniques.

Through this project, I gained practical experience with Python programming, file handling, regular expressions, data structures, and basic NLP techniques. I also improved my understanding of developing a project step by step and testing its functionality.
